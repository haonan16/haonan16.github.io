# Figure Obvious Motion Assets

Paper-ready working set for figures where movement needs to be visually obvious.

## Contents

- `motion_trace_videos/`: 2x3 six-direction grids with colored trajectory tails and arrowheads burned in. These prioritize legibility over clean qualitative display.
- `figure_frames/`: first/final PNG exports from each trace video plus a final-frame contact sheet for quick figure selection.
- `motion_tail_stills/`: selected high-motion still panels from `direction_tail_panels_A_step25750_2026-05-06`.
- `long_clean_videos/`: selected clean longer or bright six-direction videos for supplemental use.

## Selection

Selected by a simple visible-motion heuristic: tracked displacement from per-episode JSON combined with video/panel brightness. RAD had strong numerical motion but was excluded from the main copied bright-video set because existing notes mark those clips as near-black.

No existing source videos were moved or deleted.
